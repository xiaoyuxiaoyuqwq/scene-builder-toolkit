# 场景构建工具包（Three.js Scene Builder Toolkit）

> 一句话出 3D 场景 —— 多维度扩展工作流 + 程序化建模 + 单文件 HTML

## 是什么

一套 **AI 驱动的 Three.js 程序化场景**生成工具。用户只用一句话描述想法，AI 从氛围/视角/精度/色彩/元素等多个维度展开选项，逐轮确认后生成完整 HTML 单文件场景。

## 场景预览

### 长安·坊市

唐代长安城坊市的 5×5 微缩沙盘。中式木构建筑（台基+立柱+飞檐+曲面屋顶+脊饰）、街道、城墙、四门城楼、树木、NPC。

> 拖拽旋转 · 滚轮缩放 · 自动缓转

### 空间站对接

地球轨道上的环形旋转空间站。晨昏交界光照，地球 Shader（昼夜分界+城市夜光+大气辉光），对接飞船缓动接近。

### 圣林神殿

温带古林中的隐世圣殿。三角山墙石构神殿（三层台基+列柱+火盆），瀑布、萤火虫（脉冲发光）、飞鸟、薄雾、散石。

## 快速开始

1. 浏览器直接打开任意 `.html` 文件即可
2. 或拖拽到浏览器窗口
3. **无需安装、无需构建、无需后端**

所有依赖通过 CDN (jsdelivr) 动态加载 Three.js。

## 工作流（场景构建.skill.md）

```
用户一句话描述
    ↓
[识别场景类型] → 古风/太空/自然/赛博/城市
    ↓
[轮次 1] 核心氛围（时辰/光照/背景）
    ↓
[轮次 2] 视角与运镜
    ↓
[轮次 3] 细节精度 + 色彩主题
    ↓
[轮次 4] 特殊元素（多选）
    ↓
确认 → 生成单文件 HTML
```

## 核心技术

- **部件拆解叠加法**：每个物体不是 1 个几何体，是 5-15 层 —— 如神殿 = 台基×3 + 立柱×4（底座+柱身+柱头）+ 墙壁×3 + 三角山墙 + 金饰 + 火盆×2（座+碗+火焰×2）
- **共享材质 M.\* 对象**：全局唯一，不在函数内 new
- **CDN importmap**：零构建依赖，开箱即用
- **程序化 Shader**：地球昼夜分界 + 城市夜光 + 大气辉光（空间站场景）
